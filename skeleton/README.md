# {{GAME_ID}}

Jeu JumPHP. Depuis la racine du dépôt :

```bash
bin/jumphp install {{GAME_ID}}   # dépendances
bin/jumphp run {{GAME_ID}}       # jouer sur le bureau
bin/jumphp test {{GAME_ID}}      # vérifications + test automatique sans écran
bin/jumphp build {{GAME_ID}}     # version navigateur -> dist/web
bin/jumphp serve {{GAME_ID}}     # http://localhost:8080
```

Commandes : flèches / WASD pour bouger, Espace pour sauter, Échap pour la pause.
