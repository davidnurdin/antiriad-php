# pong

Jeu JumPHP. Depuis la racine du dépôt :

```bash
bin/jumphp install pong   # dépendances
bin/jumphp run pong       # jouer sur le bureau
bin/jumphp test pong      # vérifications + test automatique sans écran
bin/jumphp build pong     # version navigateur -> dist/web
bin/jumphp serve pong     # http://localhost:8080
```

Commandes : joueur 1 W / S, joueur 2 flèches haut / bas, Échap pour la pause. En ligne : `bin/jumphp relay up`, puis ONLINE dans le menu.
