# antiriad-php

Après l'apocalypse nucléaire, Tal, un guerrier tribal, part à la recherche d'une armure sacrée venue de l'ancien monde. Avec elle, il doit libérer la Terre des envahisseurs qui l'occupent. Un jeu de plateformes et d'exploration rétro, d'après le classique de 1986.

**Play: https://jumphp.net/antiriad-php**

Made with [JumPHP](https://github.com/davidnurdin/jumPhp): retro games in PHP, on the desktop and in the browser.
The game is in `games/antiriad-php/`.

```bash
bin/jumphp install antiriad-php    # dependencies (everything runs in Docker)
bin/jumphp run antiriad-php        # play on the desktop
bin/jumphp test antiriad-php       # checks + a headless demo
```
