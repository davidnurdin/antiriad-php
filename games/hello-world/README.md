# hello-world

The smallest JumPHP game: a title menu (play, sound on / off, quit), a text that moves with the arrows and
a sound on Space. Two files: `src/Scene/TitleScene.php` and `src/Scene/HelloScene.php`. It is the start of
the JumPHP playground's tutorials.

```bash
bin/jumphp install hello-world
bin/jumphp run hello-world       # desktop
bin/jumphp test hello-world      # checks + a headless self-playing demo
bin/jumphp build hello-world     # browser -> dist/web
```
