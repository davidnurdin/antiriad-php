# breakout

Jeu JumPHP (casse-briques). Depuis la racine du dépôt :

```bash
bin/jumphp install breakout   # dépendances
bin/jumphp run breakout       # jouer sur le bureau
bin/jumphp test breakout      # vérifications + test automatique sans écran
bin/jumphp build breakout     # version navigateur -> dist/web
bin/jumphp serve breakout     # http://localhost:8080
```

Commandes : flèches gauche / droite (ou A / D) pour la raquette, Espace pour lancer la balle, Échap ou P pour la pause.
